# User flow (judge walkthrough)

## Happy path (~5 minutes)

1. **Land** on `/` — click Sign in (or Open app in demo mode).  
2. **Dashboard** `/app` — click **New move**.  
3. **Residence** — search and select one current city/neighborhood. Continue.  
4. **Targets** — choose Homes / Areas / Region:
   - Homes: add 1–3 scouted apartments.  
   - Areas: add candidate cities/neighborhoods.  
   - Region: type e.g. `Oregon, USA`.  
5. **Tastes** — add ritual places, optional tags, leave “Infer from residence” on, pick Balanced. Continue.  
6. **Run** — click Rank destinations; watch progress steps.  
7. **Results** — open the destination dropdown; review matches, mismatches, expect bullets, venues.  
8. **Compare** — pick two destinations → Compare.  
9. **Export PDF** — download styled brief for the selected destination.

## Talking points for judges

- Cultural intelligence is the differentiator: rankings collapse without Qloo compare/insights.  
- Continuity is Carry’s metric (documented disclaimer on results + PDF).  
- Three target modes cover “I already scouted homes,” “I have a city list,” and “same state, surprise me.”
